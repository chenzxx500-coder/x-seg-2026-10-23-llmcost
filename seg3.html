五、Batch API：不着急的任务，走批处理拿 5 折

夜间跑的离线任务——数据标注、批量翻译、评测打分——根本不需要实时返回。OpenAI、Anthropic、Google 的 Batch API 都是输入输出全线 5 折，代价只是等几个小时。

落地动作：把 pipeline 里能等的任务全部标出来，切到 Batch；实时链路一条不动，用户无感，账单先降一半。

六、错峰定价：把批处理任务排进"谷电"时段

DeepSeek 玩的是峰谷电价那套：工作日 01:00–04:00 和 06:00–10:00（UTC）是峰时，其余时间含周末全是谷时，谷时全线 5 折（经多家第三方价格站对照 DeepSeek 官方文档核验）。看公开价目：V4.1 Flash 输出 token 峰时 1.20 美元/百万，谷时 0.60；Pro 版输出峰时 3.96，谷时 1.98。配合上一招的 Batch 用，就是"5 折再 5 折"。

落地动作：批处理任务的调度器按 UTC 排班，避开两个峰时窗口；注意费率按请求到达 DeepSeek 的时间算，不是你本地排队的时间。

七、压输出：输出 token 比输入贵 3 到 5 倍

方程里最容易被忽视的一项：输出单价通常是输入的 3–5 倍。你让模型多说一句废话，花的钱是输入的数倍。两招：第一，用 max_tokens 给输出封顶，摘要类任务直接限定长度；第二，用结构化输出（JSON Schema）——格式一次对，减少因格式错误触发的重试调用，调用次数这个因子也顺手砍了。

落地动作：审计一下你最烧钱的三个接口，加上 max_tokens 和 JSON Schema 跑一周对比。
